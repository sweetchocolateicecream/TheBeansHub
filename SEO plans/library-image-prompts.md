# Library Page — Gemini Image Prompts

**Page:** `/library/index.html`
**Style for every image:** photorealistic editorial coffee photography — natural window light, shallow depth of field, soft shadows, neutral cream/oat backdrop, subtle film grain. Avoid text, logos, watermarks, oversaturation, stock-photo gloss, or cartoon styling.

There are 28 emoji slots on the page, but many sit on cards that point to the same post. Below are **24 unique prompts** — 22 for the post cards (each one shared by its sidebar duplicate), 1 for the big featured tile, and 1 for the "See all picks" card. Wherever a sidebar thumb reuses a post, just crop the post's image to 1:1.

## Implementation note

When you generate each image, save it into `/img/` with a slug-matching filename (e.g. `specialty-coffee-malaysia.jpg`). Then in `library/index.html` replace each emoji with:

```html
<img src="/img/specialty-coffee-malaysia.jpg" alt="Specialty coffee in Malaysia" loading="lazy">
```

…and add a CSS rule like `.post-card-img img { width:100%; height:100%; object-fit:cover; }` so the image fills the card the same way the emoji does today.
