Section 04
Slide Type Catalogue
Five core slide types cover every carousel format. Every carousel should open with a Hook, close with a CTA, and use 2–4 Content/List/Steps slides in the middle.
Slide Type 01
Hook

Opens the carousel. Must earn the swipe in 2 seconds.

  • → Eyebrow pill (slide topic label)
  • → Display H1 (102px) — the myth/hook/question
  • → Subhead (42px) — one-line setup
  • → Footer: brand name + "Swipe →"
Slide Type 02
Content / Reveal

Body of the carousel. One idea per slide.

  • → Eyebrow pill (e.g. "The Truth", "Actually")
  • → H1/H2 heading — the reveal
  • → Truth card — explanation block
  • → Note line (funny/honest aside)
  • → Ghost number bottom-right
Slide Type 03
List

Multiple parallel points — 3 to 5 items max.

  • → Eyebrow pill (optional)
  • → H2 heading — the list topic
  • → 3–5 list item cards (label + body)
  • → Footer with "Next →" or slide count
Slide Type 04
Steps

Numbered sequential flow. How-to or process slides.

  • → H2 heading — what the steps achieve
  • → 3–4 step items (circle num + title + desc)
  • → Tagline block below steps (optional)
  • → Footer brand + CTA text
Slide Type 05
CTA (Closing)

Final slide. Converts engagement to platform visit.

  • → H2 — reward/payoff for reading
  • → Tagline block (what platform does)
  • → CTA block (Green bg + URL)
  • → Optional: faint photo band at bottom

Section 07
Production Rules
Non-negotiable constraints for every carousel produced under this system.
RuleDetail
Slide count 5–7 slides. Under 5 = too thin. Over 7 = drop-off climbs sharply.
Slide structure Always: Hook (1) → Content/List/Steps (2–5) → CTA (last). Never open with CTA, never skip the hook.
One idea per slide If a slide contains two separate insights, split it into two slides. Dense slides reduce saves and shares.
Font Arial/Helvetica only. No web fonts, no Google Fonts, no decorative typefaces. Consistency across all exports.
Color purity Only tokens defined in Section 01. Opacity variants are allowed; new hex values are not.
Brand bar Present on every slide, every time. Never remove. Slide count must match actual total (e.g. "3/5" on slide 3 of 5).
CTA URL Always thebeanshub.com. Never a UTM link on the slide itself (use link-in-bio for tracking).
Export format Append ?slide=N to carousel HTML URL to isolate each slide. Screenshot at 1080×1350 for upload. PNG preferred over JPG.
Dark variant Use at most once per 3 carousels. Hook slide only — never a content or CTA slide in dark mode.
Ghost numbers Use on content/reveal slides. Omit on dense list slides or when a large card occupies the bottom-right corner.
Humor/aside lines Every content slide should end with a note line that is honest, slightly self-aware, or funny. It humanises the brand and boosts saves.
Platform mentions Name-drop The Beans Hub by function: "The Beans Hub lets you filter by…" not "Check out our platform." Functional first, promotional second.
DO
  • Use eyebrow pills to set context before the heading lands
  • Keep note/aside lines short — one sentence, conversational
  • Name specific roasters, origins, taste notes
  • End every CTA with thebeanshub.com
  • Match ghost number to actual slide position
  • Use "swipe →", "keep going →", "last one →" in footer swipe prompts
  • Let the truth card carry the explanation; keep headings punchy
DON'T
  • Introduce new colors or fonts
  • Put two truth cards on one slide
  • Write slide text that requires 10+ seconds to read
  • Use "premium", "artisanal", or "journey" in copy
  • Place the CTA block on slide 1–3
  • Omit the brand bar on any slide
  • Use exclamation marks in heading text
  • Make the hook slide too gentle — it must provoke a reaction
Section 08
Voice Quick-Reference
Brand voice distilled for slide copy. Full detail in brand-voice.md.
Audience

Urban Malaysian, 22–35, home brewer. Curious, not expert. Buys from 1–2 roasters already. Open to exploring more if it's easy. High word-of-mouth potential.

Tone on slides

Warm and direct. Sounds like a knowledgeable friend, not a brand. No hype, no gatekeeping. Uses "you" naturally. Honest about complexity — never dumbs down.

Hook formulas

"[Myth statement]." / "Why your [thing] [problem]." / "[Number] things about [topic] nobody explained." / "If you like [X], you should know about [Y]."

Note line formulas

"[Honest reaction]. [funny]." / "No shame. [reassurance]." / "[Self-aware observation about coffee culture]." / "Coffee is annoying like that."

Vocab: use freely

taste notes · roast profile · origin · single origin · washed / natural / honey · local roaster · Malaysian-roasted · discover · try · find · fruity · floral · chocolatey · nutty · bright · clean

Vocab: avoid

premium · artisanal · journey (metaphorical) · "We are proud to…" · "Don't miss out…" · excessive exclamation marks · unexplained acronyms (SCA etc.)
